How it works

Three taps and it is in the diary.

You send one link. They do the rest. Nobody emails back and forth about Tuesday.

  1. 01

    They pick a time

    Your page only offers the times you are actually free, in your timezone. Visitors somewhere else see their own local time next to it.

    1:30 PM 2:00 PM 2:30 PM
  2. 02

    They confirm

    Name, email, an optional note. The server checks the slot is still open before it saves, so two people can never book the same time.

    Name Email Confirm booking
  3. 03

    It lands on your dashboard

    The booking shows up on your dashboard within seconds. They get a calendar file. Cancel it and that time opens up again.

    2:00 PM New

Your data stays with you

Every booking is saved to one readable file on the machine you run it on. No database, no third party, no tracking scripts. Back it up by copying it.

Run it

One command on your laptop. Any Node host when you want a public link.

Terminal 
$ npm start

  Free Booking Page is running

  Booking page   http://localhost:4517/book
  Dashboard      http://localhost:4517/admin

On your laptop

You need Node.js 18 or newer and nothing else. There is no build step and no packages to download. It starts with a few clearly marked sample bookings that you can clear in one click.

On a server you control

Any host that runs Node will do. Set ADMIN_PASSCODE to lock the dashboard and DATA_DIR to a folder that survives restarts. The README walks through it.

What it leaves out

It does not sync with Google or Outlook calendars, and it does not send emails or video links. You check the dashboard; your guest keeps the calendar file. If you need those today, a paid scheduler is still the right tool.
